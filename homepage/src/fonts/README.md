# Fonts

In Download, pointing at the banana of macOS shows a handwritten caption. Its font comes with the website, so that it looks the same on every computer, not only on those that have a handwriting font installed. `style.css` loads it only when the card of macOS is pointed at.

|---|---|---|---|
| `DancingScript.ttf` | Dancing Script (variable, weights 400–700) | `ofl/dancingscript/DancingScript[wght].ttf` from https://github.com/google/fonts, unchanged | SIL Open Font License 1.1, in `DancingScript-OFL.txt` |

- The license must stay next to the font.
- “Dancing Script” is a Reserved Font Name: a modified copy (for example, a subset with fewer characters) must be renamed.
