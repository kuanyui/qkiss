# Icons of the buttons, and the mark of Tango Remixer

These are copies of icons from the icon themes that [Tango Remixer](https://kuanyui.github.io/tango-remixer/) remixes.
They are copies because the CI of this website does not fetch the submodules. To update one, copy it again from its path below.

- `start-here.svg`, `system-installer.svg` and `preferences-system.svg` are from the [Tango icon theme](https://github.com/kuanyui/tango-icon-theme), which comes from the Tango Desktop Project of freedesktop.org. Its `COPYING` asks users to credit "Tango Desktop Project contributors from freedesktop.org".
  - `start-here.svg` is the Start Here icon, by Jakub Steiner. It is the mark of Tango Remixer.
  - `system-installer.svg` and `preferences-system.svg` are drawn for 32 px, the smallest size the theme has as SVG for them. The buttons show them at 22 px.
- The other icons are from [Nome](https://github.com/kuanyui/nome-icon-theme), which continues the GNOME Icon Theme. Each file states its license in an SPDX comment.
