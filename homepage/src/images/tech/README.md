# Logos of the technologies

In Q&A, the answer about LLMs uses these logos as the icons of some areas of the project. The other areas use icons from `images/icons/`.

The logos are trademarks of their owners. They are only used to name the technology of each area, unaltered, without suggesting that their owners sponsor or endorse QKiSS. The footer of the website says so.

| File | Technology | Owner | Copied from | Terms |
|---|---|---|---|---|
| `python.svg` | Python | Python Software Foundation | `python-logo-only.svg` from https://www.python.org/community/logos/ | https://www.python.org/psf/trademarks/ |
| `cplusplus.svg` | C++ | Standard C++ Foundation | `cpp_logo.svg` from https://github.com/isocpp/logos | https://isocpp.org/home/terms-of-use |
| `cmake.svg` | CMake | Kitware, Inc. | `CMake-Mark-1.svg` from https://cmake.org/ | None published |
| `githubactions.svg` | GitHub Actions | GitHub, Inc. | [Simple Icons](https://simpleicons.org/) 16.33.0 (CC0 1.0) | https://brand.github.com/foundations/logo |

- Never change the drawings. `python.svg` only adds a `viewBox` to the original file, so that it scales.
- Python, C++ and CMake are the official color logos, as their owners publish them.
- GitHub publishes no file of the GitHub Actions logo. `githubactions.svg` is the path data of Simple Icons, filled with the blue that Simple Icons gives for it. The logo has only this one color.

What the owners allow, as checked in October 2026:

- **Python** and **C++**: their owners allow this use of the unaltered logo. The PSF also asks for a notice that the logo is its trademark, and that the project is not affiliated with it: the footer gives it.
- **CMake** and **GitHub Actions**: not clearly allowed. Kitware publishes no policy for the CMake logo. GitHub's guidelines only allow its permitted logos, and the Actions logo is not one of them. The author chose to use both anyway. If an owner asks to remove its logo, use a Tango icon instead, from `resources/tango-remixer/submodules/tango-icon-theme/`: `32x32/categories/applications-development.svg` (a hard hat) for CMake, `22x22/actions/view-refresh.svg` for GitHub Actions.
- **Qt**: no logo. The trademark policy of The Qt Company (https://www.qt.io/trademark) allows open-source projects the "Built with Qt" badge, but not clearly the Qt logo itself. The row "Qt / C++" shows the C++ logo only.
- **The LLMs** are named in plain text only: Microsoft, Google, OpenAI and Anthropic all restrict the use of their logos.
