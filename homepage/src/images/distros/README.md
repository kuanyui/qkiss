# Logos of the Linux distributions

The Download section of the website uses these logos to show the distributions that QKiSS packages are built for.

- The drawings come from [Simple Icons](https://simpleicons.org/) 16.33.0, which releases them under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
- Each file has the path data of Simple Icons, filled with the brand color that Simple Icons gives for that logo.
