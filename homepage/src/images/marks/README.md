# Brand marks of the buttons

`github.svg` and `gitlab.svg` are the monochrome marks from [Simple Icons](https://simpleicons.org) (CC0 1.0), unaltered. They are copied from `resources/tango-remixer/homepage/marks/`.

- They are trademarks of GitHub, Inc. and GitLab Inc.
- Both companies' brand guidelines allow using the mark as the icon of a link to one's project there. They forbid changing the mark itself, for example redrawing it, or adding outlines or effects.
- `style.css` paints them in the text color through a CSS mask, which keeps their shape.
