QKiSS

A modest renaissance of KiSS

QKiSS is a modern implementation of KiSS viewer in Qt 6, compatible with KISS/GS and FKiSS 1 & 2 specifications.

Download GitHub GitLab

Free software under GPLv3 · Linux · Windows

What is KiSS?

KiSS (Kisekae Set System) is a format of digital paper dolls. You dress the characters up by dragging their clothes with the mouse, and FKiSS scripts add interactions such as animations and sounds.

“Kisekae” comes from the Japanese word “着せ替え人形” (pronunciation: “kisekae ningyou”), meaning “dress-up dolls”.

KiSS originated from Japanese otaku subculture and personal computer enthusiasts community (particularly those using the NEC PC-9800 series) in the 1990s, and gained popularity throughout the 1990s and early 2000s.

Why QKiSS?

By 2024, the existing KiSS viewers for Linux had stopped working: fkiss can still be built but no longer runs, and GnomeKiSS depends on outdated GNOME 2 libraries that most distributions no longer ship. QKiSS is a complete rebirth inspired by both.

This project comes from nostalgia for the Windows 95/98 and GTK+ 2 era —— a lost age before Internet was polluted by AI-generated junk (this project does use some AI though). After all, life is frightening enough as it is; the real world is a hot mess, while nijigen and isekai remain a pure promised land.

Highlights

  • Full-featured, with a handy UI

    • Switch files quickly from the side panels: the sets in your folders, and the CNF files inside an archive.
    • Read the CNF, with syntax highlighting.
    • Read the docs bundled with a set.
    • Observe objects: point at any part of a doll to see its cel, object and position.
    • Check the log, which points out problems down to the line.

  • Faithful to the specs, faithful to desire

    • Implements the KISS/GS base specification, and an interpreter for the interactive scripts of FKiSS 1 & 2 (in tests, 90% of Japanese KiSS sets run fine).
    • FKiSS 3 & 4 have too few sets, almost none of them by Japanese KiSS artists, so they were not worth the bother.
    • One-click unfix: who wants to sit there clicking a fixed item over and over? Playing shouldn't feel like work.

  • And some less serious ones

    • The code of the main program is handcrafted, without LLM agents*1 (and is probably the author's last hand-written software project, so cherish it while it lasts).
    • No damn Electron, acting as if your RAM were free.
    • Linux is no longer a second-class citizen (Windows is): built with the latest Qt 6 and C++.
    • Tango-style UI icons*2 take you back to the 2000s.
    • The author is guaranteed to be politically incorrect.

*1 This website, though, was left entirely to an LLM agent, because I have no interest in spending my life writing web pages anymore...

*2 As it turned out, developing Tango Remixer, and sorting out, fixing and drawing a pile of extra tango-flavoured icons, took, without exaggeration, almost longer than developing QKiSS itself. That is why QKiSS, started in 2024, was only first released in 2026...
