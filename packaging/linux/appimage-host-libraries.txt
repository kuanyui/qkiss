# The libraries that the AppImage does not include: it uses the ones of the user's system.
# - The libraries of glibc and of GCC (libstdc++, libgcc_s) must be the ones of the system.
#   The AppImage is built on Ubuntu 24.04, so it needs glibc 2.39 or later.
# - The drivers of the graphics card come with libGL, libEGL, libdrm and libgbm of the system.
# - The other libraries are on Linux desktops, and work best in the version of the system (for example fontconfig, ALSA).

# https://github.com/AppImageCommunity/pkg2appimage/blob/15a64c20dc23a0154622ba25829364323903b6b5/excludelist
#
